# Sweet Delight - Bakery Hero Section

A clean, modern, and visually appealing hero section banner designed for premium cake shops and bakeries. This layout highlights high-quality product imagery alongside elegant typography to drive user engagement.

## 🌟 Features
* **Elegant Design:** Perfect blend of script and bold typography.
* **Call-to-Action:** Prominent "Treat Yourself" button to increase conversions.
* **Fully Responsive:** Adapts seamlessly to desktops, tablets, and mobile devices.

## 🛠️ Tech Stack
* HTML5 (Semantic structure)
* CSS3 / Tailwind CSS (Styling & layout)

## 📂 File Structure
├── index.html       # Main HTML file
├── style.css        # Custom CSS styles
└── assets/          # Images and fonts folder
    └── cake.jpg     # Hero image

## 🚀 How to Use
1. Clone this repository or copy the code.
2. Replace the image path in `index.html` with your own product photo.
3. Open `index.html` in your browser to view the banner.
